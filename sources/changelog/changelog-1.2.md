# Fartura 1.2 — Changelog

## Português

### Correções
- **Livro guia:** agora usa a cor padrão do Patchouli (marrom). A cor laranja customizada foi removida.
- **Texturas do açaí:** corrigidas para 16x16, eliminando o aviso de tamanho no log.
- **Texturas da água de coco:** ajustadas para 16x16.
- **Frigideira:** as receitas agora aparecem na categoria de comidas do livro de receitas, sem avisos de categoria desconhecida.

## English

## v1.2
- Minecraft 1.21.1
- Mod for NeoForge

### Fixes
- **Guide book:** now uses Patchouli's default brown colour. The custom orange colour has been removed.
- **Açaí textures:** fixed to 16x16, removing the texture size warning from the log.
- **Coconut water textures:** resized to 16x16.
- **Frying pan:** recipes now show under the food category in the recipe book, with no unknown-category warnings.
